## 🚧 Current project — MarketCore

> A production-ready, reusable e-commerce backend built with FastAPI + DDD + Docker.
> Designed so any developer can clone it and ship a mobile e-commerce app for their clients — without rebuilding auth, catalog, orders, and payments from scratch.

```
marketcore/
├── api-gateway/        ← JWT validation · rate limiting · routing
├── auth-service/       ← Register · login · JWT + refresh tokens
├── product-service/    ← Catalog · variants · inventory
├── order-service/      ← Cart · order lifecycle · domain events
├── payment-service/    ← Payment intents · webhook handling
├── notification-service/ ← Email · push · event-driven dispatch
└── shared/             ← Base entities · domain events · contracts
```

**Stack:** `FastAPI` · `PostgreSQL` · `RabbitMQ` · `Redis` · `Docker Compose` · `Alembic` · `SQLAlchemy 2.x async`
